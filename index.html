JPR Minutes (personal)

JPR Minutes is a personal tool used only by its developer. It uploads files that the developer created (documents, slides and recordings) from the developer's own computer to the developer's own Google Drive.

It is not offered to other users.

It uses the Google Drive API with the drive.file scope only, so it can see only the files it created.

Privacy policy

JPR Minutes は開発者本人だけが使う個人用ツールです。開発者のパソコンにある本人のファイルを、本人の Google ドライブに保存します。他の人には提供していません。
