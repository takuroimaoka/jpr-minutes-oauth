Privacy policy: JPR Minutes (personal)

Last updated: 30 October 2026

  • JPR Minutes is a personal tool used only by its developer. It is not offered to other users.
  • It uses the Google Drive API with the drive.file scope to create and update files in the developer's own Google Drive. It can access only the files it created.
  • It does not collect, sell or share any user data with anyone. No data is sent anywhere other than the developer's own Google Drive.
  • The OAuth token is stored only on the developer's own computer.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: the support email address shown on the Google sign-in screen of this app.
